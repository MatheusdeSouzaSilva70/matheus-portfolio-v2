# Matheus.dev — Portfólio moderno

Versão reformulada do portfólio de Matheus de Souza Silva.

## Estrutura

- `index.html` — estrutura das páginas
- `styles.css` — visual, responsividade e tema
- `script.js` — menu mobile, dark/light mode, scroll e animações

## Como usar

1. Coloque estes três arquivos na raiz do seu projeto.
2. Mantenha sua pasta `pdf/` para o currículo.
3. Se quiser usar uma foto sua, substitua o bloco `.profile__placeholder` do `index.html` por uma imagem.
4. Abra `index.html` no navegador.

Os links dos projetos e redes sociais foram mantidos com base no portfólio enviado.
